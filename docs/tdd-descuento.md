Suposiciones
- Todos los productos son candidatos al descuento
- El sistema recibe el valor del descuento y regresa valor total producto menos el descuento
- El valor del descuento mas el valor sin descuento debe de ser igual al producto.

Lista de escenarios
1. El sistema no debe de aceptar valores negativos, o ceros en este caso regresa Error y regresa 0 como resultado
2. El descuento no puede ser mayor al precio total del producto en este caso regresa Error y regresa 0 como resultado
3. el Sistema solo acepta numeros si no regresa 0 como resultado
