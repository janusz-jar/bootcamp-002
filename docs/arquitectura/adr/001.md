El Equipo de IT Propone usar la arquitectura Stranger Flinger

para el plan de migración del sistema OLDMAN.12.5.4 , a su nueva versión YOUNGMAN.1.0.1

ya que se requiere tener alta disponibilidad del sistema legado mientras se hacen entregas 

de valor en el nuevo sistema.



Al mantener ambos sistemas vivos se reducen posibles gaps en la nueva infra ya que se puede

balancear el sistema legado en caso de inconvenientes y viseverza se puede aprovechar las 

bondades y nuevas cualidades de los nuevos los features migrados.
